# MIPS Assembly Tree Traversal

This project contains MIPS Assembly code for:

- Copying arrays based on a tree structure representation.
- Searching for a target in the array.
- Returning different levels based on the target's position.

## Project Structure

- `procedure1`: Copy from array1 to array2 based on a tree structure.
- `procedure2`: Copy back from array2 to array1.
- `procedure3`: Search for a target and determine its level (level 0, 1, 2, or 3).
- `procedure4`: Calls procedure2 and procedure3 together.

## How it Works

- The program loads array1, transforms it to array2.
- Searches for a target value and determines its level.
- Stack management is properly handled by saving/restoring registers.

## How to Run

You can run this MIPS code using a MIPS simulator like **SPIM** or **MARS**.
